0.2.5.1_release/ Versions are numbered like this: (MAJOR.MINOR.PATCH.FIX_RELEASE TYPE). Releases are categorized under 3 different types. [release] for publicly released versions (example: V0.1.6.0_release for V0.1.6, V0.1.6.1_release for V0.1.6b, etc). [preview] for a usually private, preview version of an upcoming public release (example: V0.1.7.0_preview for a preview version of the V0.1.7 update). And [development] for a development build of an upcoming update that is released to development testers (example: V0.1.5.0_development for a development build of the V0.1.5 update).
